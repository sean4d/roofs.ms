# Drop real photography here

Name each file after the slot it should fill, then run:

```
npm run images:ingest
```

Run `npm run images:ingest` with this folder empty to print every available
slot and where it appears on the site.

| File to drop                 | Where it appears                        |
|------------------------------|-----------------------------------------|
| `holiday-hero-estate.jpg`    | Homepage hero, holiday mode             |
| `hoa-entrance.jpg`           | HOA segment tile and HOA vertical hero  |
| `retail-center.jpg`          | Commercial segment tile and vertical    |
| `colonial-columns.jpg`       | Residential segment tile                |
| `installer-roof.jpg`         | "Why a roofing company" section         |
